Samudra is an industrial pump monitoring and control dashboard that lets operators start, stop, and monitor pumps from anywhere — on a desktop browser in the control room or a phone screen in the field. Every control is built for gloved-thumb use, high-contrast outdoor readability, and instant response.

## Designed for the Field

Samudra's interface is built for real-world operating conditions:

- **Large touch targets** — all primary controls meet a minimum 56 px height for reliable gloved-thumb operation
- **High contrast** — status colors are chosen for legibility in direct sunlight
- **Immediate feedback** — control commands are acknowledged within milliseconds, with clear visual confirmation of the new state
- **Emergency Stop is always visible** — the crimson Emergency Stop button sits adjacent to the ON/OFF switch and is never obscured by other UI elements
