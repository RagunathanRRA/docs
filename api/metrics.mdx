## Overview

The Metrics API provides access to real-time sensor readings from pump hardware, as well as historical time-series data for trend analysis, reporting, and alerting integrations. All metric values are sourced directly from the pump's onboard sensors and transmitted via the Samudra agent running on the pump controller.

---

## Get Current Metrics

Returns the most recent sensor readings for a specific pump.

```
GET /v1/pumps/{id}/metrics
```

### Path Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | Yes | The unique pump ID (e.g., `pump_abc123`). |

### Example Request

```bash
curl https://api.samudra.io/v1/pumps/pump_abc123/metrics \
  -H "Authorization: Bearer sk_live_your_api_key_here"
```

### Example Response

```json
{
  "pump_id": "pump_abc123",
  "recorded_at": "2024-03-15T14:32:00Z",
  "flow_rate": 142.7,
  "pressure": 3.82,
  "temperature": 28.4,
  "runtime_seconds": 18340
}
```

### Response Fields

<ResponseField name="pump_id" type="string">
  The ID of the pump these readings belong to.
</ResponseField>

<ResponseField name="recorded_at" type="string">
  ISO 8601 timestamp of when these readings were captured by the pump's sensors.
</ResponseField>

<ResponseField name="flow_rate" type="number">
  Volume of fluid being pumped, in **litres per minute (L/min)**.
</ResponseField>

<ResponseField name="pressure" type="number">
  Discharge pressure measured at the pump outlet, in **bar**.
</ResponseField>

<ResponseField name="temperature" type="number">
  Motor or fluid temperature, in **degrees Celsius (°C)**.
</ResponseField>

<ResponseField name="runtime_seconds" type="integer">
  Cumulative number of seconds the pump motor has been running since its last reset or installation.
</ResponseField>

## Get Metrics History

Returns a time-series array of sensor readings for a specific pump over a configurable time window.

```
GET /v1/pumps/{id}/metrics/history
```

### Path Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | Yes | The unique pump ID (e.g., `pump_abc123`). |

### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `from` | string | Yes | Start of the time window (ISO 8601, e.g., `2024-03-15T00:00:00Z`). |
| `to` | string | Yes | End of the time window (ISO 8601, e.g., `2024-03-15T23:59:59Z`). |
| `resolution` | string | No | Aggregation interval for returned data points. One of `1m`, `5m`, `1h`, or `1d`. Default: `5m`. |

<Note>
  When a `resolution` coarser than `1m` is specified, each data point is a **downsampled average** of all raw readings within that interval. For example, a `1h` resolution returns one reading per hour where `flow_rate`, `pressure`, and `temperature` are averaged across all readings captured in that hour. If no readings were received during a given interval (e.g., the pump was offline), that interval will be omitted from the response array.
</Note>

### Example Request

```bash
curl "https://api.samudra.io/v1/pumps/pump_abc123/metrics/history?from=2024-03-15T00:00:00Z&to=2024-03-15T02:00:00Z&resolution=1h" \
  -H "Authorization: Bearer sk_live_your_api_key_here"
```

### Example Response

```json
{
  "pump_id": "pump_abc123",
  "from": "2024-03-15T00:00:00Z",
  "to": "2024-03-15T02:00:00Z",
  "resolution": "1h",
  "data": [
    {
      "timestamp": "2024-03-15T00:00:00Z",
      "flow_rate": 138.2,
      "pressure": 3.75,
      "temperature": 27.1,
      "runtime_seconds": 10800
    },
    {
      "timestamp": "2024-03-15T01:00:00Z",
      "flow_rate": 141.9,
      "pressure": 3.80,
      "temperature": 27.8,
      "runtime_seconds": 14400
    },
    {
      "timestamp": "2024-03-15T02:00:00Z",
      "flow_rate": 143.4,
      "pressure": 3.84,
      "temperature": 28.3,
      "runtime_seconds": 18000
    }
  ]
}
```

### Response Fields

| Field | Type | Description |
|---|---|---|
| `pump_id` | string | The ID of the pump these readings belong to. |
| `from` | string | The start of the queried time window (ISO 8601). |
| `to` | string | The end of the queried time window (ISO 8601). |
| `resolution` | string | The aggregation interval used for the returned data. |
| `data` | array | An ordered array of metric snapshots, each with the fields described in [Get Current Metrics](#get-current-metrics). |

### Error Responses

| HTTP Status | Error Code | Description |
|---|---|---|
| `400 Bad Request` | `invalid_time_range` | `from` is after `to`, or either value is not a valid ISO 8601 timestamp. |
| `400 Bad Request` | `invalid_resolution` | The `resolution` value is not one of the accepted options. |
| `404 Not Found` | `pump_not_found` | No pump with the given ID exists in your organization. |
