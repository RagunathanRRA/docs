The Pumps API provides read access to every pump registered in your Samudra organization. Use it to enumerate your fleet, check connectivity and running state, and retrieve configuration details for a specific unit before issuing control commands.

## The Pump Object

Every pump endpoint returns pump objects with the following fields:

<ResponseField name="id" type="string">
  Unique identifier for the pump, prefixed with `pump_`. Example: `pump_abc123`.
</ResponseField>

<ResponseField name="name" type="string">
  Human-readable display name for the pump as configured in the dashboard.
</ResponseField>

<ResponseField name="location" type="string">
  Physical location or site description associated with this pump (e.g., `"Site A - North Well"`).
</ResponseField>

<ResponseField name="status" type="string">
  Network connectivity state of the pump. One of `online` or `offline`.
</ResponseField>

<ResponseField name="running_state" type="string">
  Current operational state of the pump motor. One of `on` (actively pumping) or `off` (motor stopped).
</ResponseField>

<ResponseField name="ip_address" type="string">
  Local network IP address of the pump controller. May be `null` if the pump has never connected.
</ResponseField>

<ResponseField name="last_seen_at" type="string">
  ISO 8601 timestamp of the last successful heartbeat received from the pump.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the pump was first registered in your organization.
</ResponseField>

## List All Pumps

Retrieves a paginated list of all pumps registered in your organization.

```
GET /v1/pumps
```

### Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `status` | string | No | Filter by connectivity status. One of `online` or `offline`. |
| `running_state` | string | No | Filter by operational state. One of `running` or `stopped`. |
| `limit` | integer | No | Number of results to return per page. Default: `20`. Maximum: `100`. |
| `offset` | integer | No | Number of results to skip for pagination. Default: `0`. |

### Example Request

```bash
curl "https://api.samudra.io/v1/pumps?status=online&limit=10" \
  -H "Authorization: Bearer sk_live_your_api_key_here"
```

## Get a Single Pump

Retrieves full details for a specific pump by its ID.

```
GET /v1/pumps/{id}
```

### Path Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `id` | string | Yes | The unique pump ID (e.g., `pump_abc123`). |

### Example Request

```bash
curl https://api.samudra.io/v1/pumps/pump_abc123 \
  -H "Authorization: Bearer sk_live_your_api_key_here"
```

### Example Response

```json
{
  "id": "pump_abc123",
  "name": "Main Intake Pump 1",
  "location": "Site A - North Well",
  "status": "online",
  "running_state": "on",
  "ip_address": "192.168.1.45",
  "last_seen_at": "2024-03-15T14:32:00Z",
  "created_at": "2024-01-10T09:00:00Z"
}
```

### Error Responses

| HTTP Status | Error Code | Description |
|---|---|---|
| `404 Not Found` | `pump_not_found` | No pump with the given ID exists in your organization. |
